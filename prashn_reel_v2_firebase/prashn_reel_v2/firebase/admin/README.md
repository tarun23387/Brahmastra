# एडमिन पैनल — हाथ से प्रश्न जोड़ने के लिए

यह आपके अपने कंप्यूटर पर चलने वाला छोटा पैनल है। इससे Firestore में सीधे
प्रश्न जोड़े, बदले और हटाए जा सकते हैं — बिना Firebase Console खोले।

## चलाना

```bash
cd firebase/admin
npm install
npm start
```

फिर ब्राउज़र में खोलें: **http://localhost:4000**

बंद करने के लिए टर्मिनल में `Ctrl+C`।

## ⚠️ सुरक्षा

यह सर्वर `firebase/seed/serviceAccountKey.json` इस्तेमाल करता है, जिसके पास
**पूरे डेटाबेस का पूरा अधिकार** होता है। इसीलिए यह सिर्फ़ `127.0.0.1` पर सुनता है।

* इसे कभी किसी public server या इंटरनेट पर मत चलाइए
* `serviceAccountKey.json` कभी git में commit मत कीजिए (`.gitignore` में है)
* यह पैनल जान-बूझकर बिना पासवर्ड का है — क्योंकि यह सिर्फ़ आपके लैपटॉप पर चलता है

## क्या-क्या कर सकते हैं

| काम | कैसे |
|---|---|
| नया प्रश्न | बाएँ फ़ॉर्म में भरें → **सेव करें** |
| सही उत्तर चुनना | विकल्प के आगे वाले **गोले (अ/ब/स/द)** पर क्लिक करें — हरा हो जाएगा |
| प्रश्न बदलना | सूची में **बदलें** → फ़ॉर्म भर जाएगा → **सेव करें** |
| प्रश्न हटाना | सूची में **हटाएँ** (पुष्टि पूछेगा) |
| खोजना | ऊपर के खाने में प्रश्न या विकल्प का कोई शब्द |
| विषय से छाँटना | ड्रॉपडाउन से विषय चुनें |

## जाँच जो अपने आप होती है

सेव करने से पहले पैनल यह सब देखता है — ताकि ऐप में कोई टूटा प्रश्न न पहुँचे:

* प्रश्न खाली न हो
* ठीक **4 विकल्प** हों, कोई खाली न हो
* दो विकल्प एक जैसे न हों
* सही उत्तर चुना गया हो (0–3)
* विषय `lib/models.dart` वाली सूची में से हो
* व्याख्या लिखी हो
* **वही प्रश्न पहले से मौजूद तो नहीं** — हो तो चेतावनी के साथ रुक जाएगा

ये नियम `lib/models.dart` के `Question.fromMap` से मेल खाते हैं। अगर वहाँ
विषय जोड़ें या बदलें, तो `server.js` की `SUBJECTS` सूची भी वैसी ही कर दीजिए।

## प्रश्नों की id

हाथ से जोड़े प्रश्नों की id अपने आप बनती है: `man-0001`, `man-0002` …

इनमें **`expiresAt` फ़ील्ड नहीं लगती**, इसलिए cleanup function इन्हें कभी नहीं
हटाएगा — बिल्कुल seed प्रश्नों की तरह। सिर्फ़ AI से बने साप्ताहिक प्रश्न ही
15 दिन बाद हटते हैं।
